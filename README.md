# Fahmy AI — Mobile Prototype

نسخة أولى PWA قابلة للتثبيت على الهاتف.
- واجهة عربية RTL
- مساعد تجريبي
- مشاريع وشخصيات وأفكار محفوظة في LocalStorage
- مولد مشهد تجريبي
- قاعدة أدوات AI تجريبية
- Service Worker للتثبيت/العمل الأساسي دون اتصال

## تشغيل
افتح index.html عبر استضافة HTTPS أو شغّل خادم محلي. على الهاتف استخدم "Add to Home Screen".

## الخطوة التالية
توصيل Backend آمن لنموذج AI حقيقي + قاعدة بيانات + مزامنة + مصادر رسمية لتحديث أدوات AI.
